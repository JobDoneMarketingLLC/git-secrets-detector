Git Pre-Commit Secrets Detector

Stop accidental commits of API keys, tokens, and passwords. This pre-commit hook scans staged changes and blocks the commit if secrets are found.

How it works

  1. Install the hook in your repository (or globally).
  2. Stage files with git add.
  3. Run git commit – the hook scans all staged diffs against known patterns (AWS keys, GitHub tokens, generic passwords, etc.).
  4. If a secret is detected, the commit is aborted and a report is shown.

The Hook Script

Copy the script below into .git/hooks/pre-commit (make it executable with chmod +x .git/hooks/pre-commit).

#!/bin/bash
# Git pre-commit hook to detect secrets in staged changes

# Patterns to detect (customise as needed)
PATTERNS=(
  'AKIA[0-9A-Z]{16}'                              # AWS Access Key ID
  'sk_live_[0-9a-zA-Z]{24}'                       # Stripe live secret key
  'ghp_[0-9a-zA-Z]{36}'                           # GitHub personal access token (classic)
  'gho_[0-9a-zA-Z]{36}'                           # GitHub OAuth token
  'ghu_[0-9a-zA-Z]{36}'                           # GitHub user-to-server token
  'ghs_[0-9a-zA-Z]{36}'                           # GitHub server-to-server token
  'glpat-[0-9a-zA-Z]{20}'                         # GitLab personal access token
  'xox[baprs]-[0-9a-zA-Z]{10,}'                   # Slack token
  'AIza[0-9A-Za-z\-_]{35}'                        # Google API key
  '(?i)(password|passwd|pwd|secret)[:\s]*[^\s]+'  # Generic password assignment
)

echo "🔍 Scanning staged files for secrets..."

# Get the list of staged files (excluding deleted)
STAGED_FILES=$(git diff --cached --name-only --diff-filter=ACM)

if [ -z "$STAGED_FILES" ]; then
    echo "✅ No staged files. All good."
    exit 0
fi

FOUND_SECRET=0

# Iterate over staged files and check their diff
while IFS= read -r file; do
    # Show only added/modified lines
    DIFF_CONTENT=$(git diff --cached --unified=0 "$file" | grep '^+')
    while IFS= read -r pattern; do
        if echo "$DIFF_CONTENT" | grep -E "$pattern" > /dev/null 2>&1; then
            echo "❌ Potential secret detected in $file matching pattern: $pattern"
            FOUND_SECRET=1
        fi
    done <<< "${PATTERNS[@]}"
done <<< "$STAGED_FILES"

if [ $FOUND_SECRET -eq 1 ]; then
    echo ""
    echo "🚫 Commit blocked. Remove secrets before committing, or use 'git commit --no-verify' to bypass."
    exit 1
fi

echo "✅ No secrets detected. Proceeding with commit."
exit 0

Installation

  1. Copy the script into your repository's .git/hooks/pre-commit file.
  2. Make it executable: chmod +x .git/hooks/pre-commit.
  3. Optionally, install globally by saving it as a custom hooks template (see git config core.hooksPath).

Then simply commit as usual – the hook runs automatically.

Bypass in an emergency

If you are sure a match is a false positive, commit with git commit --no-verify to skip the hook.
